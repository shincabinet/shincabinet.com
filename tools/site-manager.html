How this works

This manager edits assets/js/content.js and config/pages.js, creates character profile folders automatically, and regenerates sitemap.xml. Website content uses stable siteimg_… IDs. The Media library maps each site image to a Raspberry Pi img_… ID, so characters and gallery entries never need Pi IDs entered manually.
