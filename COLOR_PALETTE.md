# Shin Cabinet — Minimal Light Palette

The site now uses a quiet, warm off-white layout inspired by the sparse presentation of FishmanWorks. Most visual color comes from the artwork itself.

- Background: `#FBFAF6`
- Secondary surface: `#F2EFE8`
- Primary text: `#171717`
- Muted text: `#7B7974`
- Hairline borders: `#DEDBD3`
- Shin rust accent (hover only): `#B9472E`

The accent is intentionally rare. Navigation, titles, filters, cards, and pricing should stay mostly black/gray so the site reads as a personal art site instead of an ad landing page.
